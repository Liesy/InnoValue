## 2. 经济学特征观察

1. **估值离散度大**：Tobin's Q 均值为 4.60，但最高达到 20.41，标准差为 3.75，这说明样本内不同公司、甚至同公司不同统计期的估值溢价差距十分明显，非常适合通过回归分析来挖掘背后的异质性成因。
2. **研发投入的偏态分布**：从研发强度的均值（3.9%）与中位数（3.1%）看出，这批企业普遍保持了一定的研发惯性投入。将研发资金自然对数化大大缩小了原有量级跨界带来的方差。
3. **滞后项样本折损**：在时间轴向下平移1阶后，由于非平衡面板的部分时间窗口未连贯或属于该公司的最初年份观测序列，导致滞后特征列可用样本量微降。
4. **控制变量的合理性**：ROE均值为 8.3%，符合市场一般水平；负债率大多集中在 17% 到 44% 之间（均值 33%），体现公司整体的财务杠杆尚属稳健。

后续将排查这些特征之间是否存在强烈的多重共线性风险。

## 💻 附：Python 代码小白通俗解析
这步对应的代码在 `src/03_descriptive_stats.py` 文件中，它的职责是“给数据做一次全身体检，出集体体检报告”。这比我们在 Excel 里一个个手拉算平均值快多了。

#### 核心指令：一键生成全科体检单
```python
# vars_to_describe 是一个装满我们要检查的指标名字的袋子
vars_to_describe = ['TobinQ', 'ln_RD', 'RD_Intensity', 'ROE', '净利润增长率']

# df[vars_to_describe] 从大表里把这些列抽出来
# .describe() 就是这个全能体检仪，它会瞬间算出这些列的：总人数(count)、平均分(mean)、波动情况(std)、最高分最小值等等
# 最后的 .T 的意思是转置(Transpose)，也就是原本横向太长不好阅读，把行和列对调一下，让人看得更舒服
stats_df = df[vars_to_describe].describe().T
```
**解读**：就像是教导主任拿到了全年级的成绩单，输入一个 `.describe().T` 咒语，系统瞬间吐出一张漂亮的表格：语文平均分多少、数学最高分是谁、英语及格线在哪，全部整整齐齐排在了一张图上。就是本章展示的那张 Markdown 表格的由来。
