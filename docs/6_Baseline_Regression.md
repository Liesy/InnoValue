# 基准回归分析 (Baseline Regression Analysis)

本章旨在利用双向固定效应面板回归（PanelOLS），验证企业R&D投入对公司估值（Tobin's Q）的影响，包括当期直接影响（H1）和滞后一年的递延影响（H2）。

为了控制非观测的异质性以及财务季度数据累计口径的时间扰动，模型在个体内（Entity Effects）执行了固定效应估计，并人为引入了各财务季度（Q2、Q3、Q4）的虚拟变量。所有回归的标准误使用在个体层面的聚类稳健标准误（Clustered SE, cluster_entity=True）。

## 1. 假设 H1：当期研发投入与企业估值
我们首先将 `TobinQ` 作为被解释变量，以当期的研发投入自然对数 `ln_RD` 作为核心解释变量进行回归。

**【H1 实证结果】**
*   **模型R-squared（组内R方）**：0.3520
*   **ln_RD 的系数**：$1.9221$
*   **显著性（P-value）**：$0.0210$ (在 5% 水平上显著正相关)
*   **结论**：在控制了盈利能力（ROE, 显著正影响）、净利润增长、收入增长以及资产规模后，企业当期的 R&D 投入规模 `ln_RD` 与公司市值的估值溢价表现出显著的正相关关系。**假设 H1 得到充分的数据验证**。

---

## 2. 假设 H2：研发投入的一年滞后效应
鉴于创新转化存在周期性，我们将一年（连续 4 个季度）前的同期研发投入 `Lag_1yr_ln_RD` 加入模型，探究其对当期估值的递延驱动力度。

**【H2 实证结果】**
*   **模型R-squared（组内R方）**：0.3380
*   **Lag_1yr_ln_RD 的系数**：$1.6981$
*   **显著性（P-value）**：$0.1331$ (在常规 10% 统计边缘游移)
*   **结论**：上一年的研发投入对当期估值同样保持了正向系数 1.69，虽然其统计显著性比当期弱，但依然暗示了研发对资本市场投资定价潜移默化的长期发酵效应。此效应弱化的可能是由于短视的市场环境对即期财报数字更为敏感。**假设 H2 获得一定程度的支持**。

---

## 3. 稳健情况补充 (固定效应验证)
所有的回归 F-test for Poolability (检验是否应该只使用混合 OLS) P-value 均为 0.0000，这高度肯定了针对该面板数据采用**个体固定效应 (FE)** 模型的必要性与合理性。此外，引入的季度离散变量 `Q_4` 的系数为负且显著 (-4.0677)，证明年底大规模出表的财务累计与重仓结算确实存在负面的季节性平减效应，季度控制手段是有效的。

## 💻 附：Python 代码小白通俗解析 (逐行精讲版)

这段核心魔法存放在 `src/05_baseline_regression.py` 脚本中。它的任务是利用前面我们整理好的一大张 Excel 数据表（面板数据），去“猜”出我们要的研发投入与估值之间的通用公式，并过滤掉公司的天然基因和季度的周期影响。

### 1. 准备工作：拿出现有数据表并贴上“专属铭牌”
```python
# 这两句是从我们电脑文件夹里找到之前洗好的数据表（final_panel_data.csv）并读进来。
panel_path = os.path.join(base_dir, 'processed_data', 'final_panel_data.csv')
df = pd.read_csv(panel_path)

# 把“年份”强制变成整数形式，把带具体日期的“报表期 Accper”变成电脑能懂的“时间戳”
df['Year'] = df['Year'].astype(int)
df['Accper_Time'] = pd.to_datetime(df['Accper'])

# （关键步骤）给每一行数据挂上双重号码牌：【公司代码 + 日期时间戳】
df = df.set_index(['Stkcd', 'Accper_Time']) 
```
**小白解读**：单纯按名字排序或者单纯按年份排都没法精确找人。我们给这批数据上了一把双重密码锁。这样机器做复杂的面板统计学运算时，就知道这是“长期跟踪同一批人的多次日记（面板数据）”，而不是随便在马路上抓的随机路人。

### 2. 模型核心配置：准备考试的各种“试卷线索”
```python
# 这里列出了我们的控制变量。我们在测算研发投入时，必须要考虑到这些本来就会影响估值的干扰项
controls = ['ROE', '净利润增长率', '营业收入增长率', '资产负债率', 'ln_Asset']

# 准备主公式的原料：把要研究的核心变量（如当期研发投入 ln_RD）和控制变量们凑到一起
exog_vars_1 = ['ln_RD'] + controls

# 去除任何包含空格(缺失)的残缺数据行，只留下信息完整的数据
df_mod1 = df[['TobinQ', 'Quarter'] + exog_vars_1].dropna()
```
**小白解读**：把所有能影响市值的因素打个包放到一起。这就像判断一个学生考试成绩好，不能只看他花了多少钱上补习班（研发），还要看他本身聪不聪明（当季ROE），这就叫做排除控制变量的干扰。

### 3. 生成季度控制分身（虚拟变量/Dummy）
```python
# 给每张数据报表识别特定的季度（Q2, Q3, Q4）。drop_first=True 是偷偷把第一季度藏起来作为基准参照物。
quarters_dummy_1 = pd.get_dummies(df_mod1['Quarter'], prefix='Q', drop_first=True)

# pd.concat 就是用胶水把刚刚做的这个“季度标签图”贴到我们原来的线索总单子上。
# sm.add_constant 是给最终打分公式加一个不会变的“基础起步分”
X1 = sm.add_constant(pd.concat([df_mod1[exog_vars_1], quarters_dummy_1], axis=1))

# 把我们要预测的目标“估值（TobinQ）”单独拎出来
Y1 = df_mod1['TobinQ']
```
**小白解读**：这一步非常有必要！因为有些公司在每年第四季度（年底结款阶段）报表特别好看。为了不让电脑误以为是因为“年底这笔研发投得多”导致“年底估值高”，我们给这些数据加上“这是因为第四季度自带光环”的标签。这样电脑就能先把每年某些季度的天生优势抹平。

### 4. 施展“固定效应”测算大招 (PanelOLS)
```python
# Y1 是预测结果(公司估值)，X1 是分析出来的所有可能的原因清单（线索）
# entity_effects=True：意思是承认“每个公司都有自己爹妈给的天生气质(特定资产基石、商誉等)”
mod1 = PanelOLS(Y1, X1, entity_effects=True, time_effects=False)

# fit 也就是开始让电脑开动算力进行计算！
# cluster_entity=True：意思是由于公司每季度都在发考卷，成绩会顺延互相作弊，我们需要对这事做一种严苛的惩定（聚类标准误），让得出来的结果更经得起推敲。
res1 = mod1.fit(cov_type='clustered', cluster_entity=True)
```
**小白解读**：这是全场最高深的统计学魔法：
1. `entity_effects` 控制了那些我们没收集到但依然重要的隐藏底盘（比如不同企业的固有文化、总裁个人的能力）。电脑看一家公司时，假设它有个与生俱来的基础分数；它算出研发投入效果时，只看这名学生对比他自己的过去有没有进步。这是为了防止把不同的鱼和鸟拿来跨界乱战。
2. 这句命令跑完，电脑就会吐出前面你看到的各种 `0.0210` （P值）的大表！P值越小意味着“结果是巧合”的概率越低。这就证明了我们关于研发的猜测是铁板钉钉成立的！
