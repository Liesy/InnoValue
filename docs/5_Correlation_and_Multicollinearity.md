# 相关性与多重共线性检验

为了确保随后的面板数据回归分析中的结果稳健且无偏，本阶段对提取的模型特征执行了 Pearson 相关系数测算和 VIF(方差膨胀因子) 共线性诊断。

## 1. 变量相关性分析

从 Pearson 相关系数矩阵中观察到：
1. **Tobin's Q 与控制变量的初探**：Tobin's Q 与 `ROE` 的相关系数为 0.311，呈现合理的正相关，高盈利能力伴随着高估值；与 `资产负债率` (-0.417) 以及 `总资产对数` (-0.423) 呈现负相关，反映出市场偏好轻资产和低杠杆高技术壁垒企业。
2. **重点关注**：`ln_RD` 与其一阶滞后项 `Lag_1yr_ln_RD` 高度自相关（系数达 0.834）。且它们与 `ln_Asset` 相关度也较高（0.86左右），表明规模越大的公司研发投入绝对额越大。

## 2. VIF 方差膨胀因子诊断

高度相关可能诱发多重共线性，使得回归系数的方差变大且显著性失真。我们使用最小二乘拟合并求逆判定 VIF 值：

| 变量特征 (Feature) | 方差膨胀因子 (VIF) |
| :--- | :--- |
| **ln_RD** (当期研发对数) | 5.969 |
| **Lag_1yr_ln_RD** (滞后1年研发)| 5.763 |
| **ROE** | 1.203 |
| **净利润增长率** | 1.709 |
| **营业收入增长率** | 2.005 |
| **资产负债率** | 2.213 |
| **ln_Asset** (总资产对数)| 5.674 |

> [!NOTE] 
> 经典的多重共线性判定阈值为 **VIF > 10**。
> 所有解释变量与控制变量的 VIF 最大值仅为 5.969，远低于警戒线 10。因此可以断定：模型中**不存在严重的多重共线性问题**，各项控制变量可以放心引入回归模型。

*建议执行：鉴于当期研发和滞后研发投入具有高共线性（VIF双双突破5），随后的基准回归中，应考虑将二者分别作为核心解释变量独立进行假设H1和H2的验证回归。*

#### 第一层：算相关系数 (查人际关系)

# df.corr(method='pearson') 命令会计算表格里每一列之间的"皮尔逊相关系数"

#### 第二层：VIF 方差膨胀检测 (揪出卧底)
多重共线性的意思是：两个变量在表达完全一样的东西。放入模型会导致程序“精神分裂”，算不出正确权重。
```python
def calculate_vif(df, features):
    for feature in features:
        # 把要考察的特征当成“被告(y)”，其他所有人当成“证人(X)”
        X = data.drop(columns=[feature])
        y = data[feature]
        ...
        # 尝试用别人来预测这个人
        # 如果能100%预测准(r_squared拉满)，说明这个人毫无存在价值，是个“卧底复制品”
        r_squared = model.score(X, y)

```
**解读**：VIF(方差膨胀因子) 就像是查卧底的探测器。比如我在考察“身高”、“腿长”对跑步速度的影响。程序会自动做个测试：用“身高”去猜“腿长”，如果一猜一个准，那 VIF 分数就会爆表（通常大于 10）。我们就知道模型里只要留个“身高”就够了，“腿长”得踢出去。这里的计算证明咱们的指标都低于 6，“身份清白”。
