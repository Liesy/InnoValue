### 1.3 关键发现与分析

**（一）被解释变量 TobinQ 与各解释/控制变量的初步关系**

- **TobinQ ↔ ROE** (r=0.320, P=0.0000)：在 1% 水平上高度显著的正相关。盈利能力越强，市场给予的估值越高，符合价值投资基本逻辑。
- **TobinQ ↔ 资产负债率** (r=-0.417, P=0.0000)：在 1% 水平上显著的负相关。高杠杆被市场视为财务风险，压低估值溢价。
- **TobinQ ↔ ln_Asset** (r=-0.446, P=0.0000)：在 1% 水平上显著的负相关。规模越大的企业，Tobin's Q 反而越低——反映出资本市场对轻资产、高技术壁垒的中小型 AI 企业给予了更高的成长性溢价。
- **TobinQ ↔ ln_RD** (r=-0.319, P=0.0000)：研发绝对金额与 Q 的简单相关系数为负。但这里的负相关是由规模混杂效应驱动的（大公司研发额高但 Q 低），而非研发本身压低估值——这恰恰说明了在回归中控制规模 (ln_Asset) 后剥离该混杂因素的必要性。
- **TobinQ ↔ 净利润增长率** (r=-0.039, P=0.5217)：不显著。单变量层面净利润增长率对估值几乎无解释力。
- **TobinQ ↔ 营业收入增长率** (r=0.005, P=0.9307)：不显著。同上。

**（二）核心解释变量之间的共线性预警**

- **ln_RD ↔ Lag_1yr_ln_RD** (r=0.987, P=0.0000)：极高的序列自相关。这意味着公司研发投入的绝对规模年际变化极小，具有极强的惯性。这两个变量**绝不可同时纳入**同一回归方程，必须分模型独立验证 H1 和 H2。
- **ln_RD ↔ ln_Asset** (r=0.863, P=0.0000)：规模越大的公司研发绝对额越大。这是设计研发强度指标 (RD_Intensity = 研发/总资产) 以剥离规模效应的核心依据。
- **资产负债率 ↔ ln_Asset** (r=0.748, P=0.0000)：规模越大的公司杠杆率越高。VIF 检验将进一步评估其是否达到有害共线性水平。

**（三）控制变量之间**

- **净利润增长率 ↔ 营业收入增长率** (r=0.655, P=0.0000)：中高度正相关，符合经济直觉（营收增长往往伴随利润增长），但 VIF 检验将确认其共线性是否在可控范围内。
- **ROE ↔ 营业收入增长率** (r=0.329, P=0.0000)：低度正相关，不构成共线性威胁。
- **ROE ↔ ln_Asset** (r=-0.014, P=0.8233)：完全不相关，各自独立。

## 2. VIF 方差膨胀因子诊断

高度相关可能诱发多重共线性，使得回归系数的方差变大且显著性失真。

> [!IMPORTANT]
> 由于当期研发 (`ln_RD`) 与各滞后期研发 (`Lag_Nyr_ln_RD`) 在实际回归中**分属不同模型**（不会同时出现在同一回归方程中），因此 VIF 必须按照各模型的实际变量组合分组计算，而非混合在一起——否则会出现虚高的 VIF (>40)。

### VIF 诊断结论

> [!NOTE]
> 经典的多重共线性判定阈值为 **VIF > 10**。
> 在全部 4 个模型组中，所有变量的 VIF 最大值仅为 **4.799**（模型1中的 ln_Asset），远低于警戒线 10。
> 值得注意的是，ln_RD/Lag_Nyr_ln_RD 与 ln_Asset 的 VIF 均在 4.1–4.8 范围内，说明两者虽然具有较高的简单相关性（Pearson r≈0.86），但在引入其他控制变量后，**条件共线性已被充分吸收，不会导致回归权重分配的严重失真**。
> 因此可以断定：各模型中**不存在严重的多重共线性问题**，各项控制变量可以放心引入回归模型。

## 💻 附：Python 代码小白通俗解析
这段代码在 `src/04_correlation_vif.py` 里，主要解决两件事："看看大家关系好不好"以及"查内鬼"。

#### 第一层：算相关系数 + P 值 (查人际关系及其可信度)
```python
# 使用 scipy.stats.pearsonr 逐对计算相关系数和双尾 P 值
# P 值回答的是"这个相关关系有多可能是碰巧的？"
for i in range(n):
    for j in range(i):
        r, p = stats.pearsonr(df.iloc[:, i], df.iloc[:, j])
```
**解读**：不仅看"关系好不好"（相关系数），还看"这段关系靠不靠谱"（P 值）。P 值越小越可信。如果 P < 0.01，我们就非常有把握说这两个变量确实存在相关性（打上 `***`），而不是随机出来的巧合。

#### 第二层：分模型 VIF 检测 (揪出卧底)
```python
# 关键改进：按实际回归模型分组计算 VIF
# 当期 ln_RD 和滞后 Lag_1yr_ln_RD 不会同时出现在一个回归里
# 所以它们的"卧底嫌疑"要分别排查
vif_groups = [
    ('模型1: 当期 ln_RD',    ['ln_RD'] + control_vars),
    ('模型2: 滞后1年 ln_RD', ['Lag_1yr_ln_RD'] + control_vars),
    ...
]
```
**解读**：VIF 就像是查卧底的探测器。现在我们学聪明了——分批审查。每个模型的"嫌疑人"名单不同，就像不同案件的涉案人员要分开审问，不能把不同案件的嫌疑人混在一起查。结果证明每一案都"身份清白"（VIF 全部低于 5）。
