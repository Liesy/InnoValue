# 稳健性检验 (Robustness Checks)

在得到基准回归支持的结论后，为确保该结果不是由于偶然的参数设定、变量选择或个别异常样本主导的，我们需要进行稳健性检验。

本章围绕更换核心解释变量展开，并在此详细评估了不同维度的稳健性检验策略在当前数据集上的可行性。

## 1. 策略评估与可行性分析

### 1.1 替换核心解释变量法 (实施 ✔️)
*   **方法思路**：在基准回归中，我们将研发投入绝对额取自然对数（`ln_RD`）作为核心解释变量。稳健性检验的一般做法是将其换成“相对比例”指标。用户指定了将“研发投入/总资产”替换为更主流的“**研发投入/营业收入**”（研发营收占比）。
*   **实施可行性**：原始数据表诸如 `利润表` 与 `盈利能力` 中未直接提供“营业总收入金额”这一绝对值。
    *   *替代方案：由于数据维度缺失无法推演出“营业总营收”，我们退而求其次利用“研发投入/总资产”（即已生成的 `RD_Intensity` ）作为替换变量进行回归。总资产是衡量企业体盘的最佳表征指标，若能剔除体型通胀因素且结果依然显著，将提供极好的稳健佐证。*

### 1.2 剔除特定样本法 (条件受限 ⚠️)
*   **实施可行性（受限原因）**：我们的数据集非常精简（总计 17 家公司的 345 条观测值）。
    *   **严重缺乏行业标识符**：数据表 `merged_data.csv` 缺乏行业代码。因此“剔除金融业”或“只保留某部分实业”无法自动化实施。
    *   **年份剔除损失率高**：总时间跨度不长，若剔除某一年（4个季度），会导致面板本就不丰满的样本量进一步削减。考虑到这点，未执行特定阶段切割。

### 1.3 改变行业固定效应法 (不可行 ❌)
*   **实施可行性（不可行原因）**：同 1.2 点。由于没有任何能够标识行业的特征列，“控制行业混合交叉固定效应”或是“按行业聚类标准误”从信息底层结构来说均不存在实现的可能空间。

## 2. 稳健回归结果：使用研发资产强度 (RD_Intensity) 替换检验
模型重新采用个体固定效应搭配聚类稳健标准误（含季度控制）进行了估计。结果发生了有趣且发人深省的变化：

**【当期研发强度的影响 (H1-稳健性)】**
*   解释变量变成了 `RD_Intensity`。
*   系数变为 `-0.2515`。
*   **显著性（P-value）**：$0.9808$ (完全不显著)。
*   **分析**：当剥离掉公司的自然规模体型后，研发资产占比极高（过于孤注一掷）的公司在当季的 Tobin's Q 并没能起飞，甚至可能遭到轻微打压。这可能是因为**重资产或当期大额现金的消耗引起了即时的估值忌惮**。

**【滞后一年同季研发强度的影响 (H2-稳健性)】**
*   解释变量为 `Lag_1yr_RD_Intensity`。
*   系数强力拉升反转为 `+8.6901`。
*   **显著性（P-value）**：$0.3063$。
*   **分析**：经历一年沉淀后，高研发投产比展现了其资本价值发酵的能力（系数由负转为大正）。但这仅存在于数值趋势方向上，因为 P > 0.1 导致其不具备强统考意义。这佐证了**即期报表对盈利敏感（ROE系数高达10.5），而对“烧钱占比高低”的忍耐度是延迟且有限的**。

**稳健性总结**：绝对资金量的投入（基准回归）是市场推高市值的显著直接驱动力；但在转为考察“下注占比”的相对强度时，效应因风险权重的介入被大幅削减，揭示了估值驱动在体量绝对值和配置相对值之间的割裂现象。
