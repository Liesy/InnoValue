# 稳健性检验 (Robustness Checks)

在得到基准回归支持的结论后，为确保该结果不是由于偶然的参数设定、变量选择或个别异常样本主导的，我们需要进行稳健性检验。

本章围绕更换核心解释变量展开，并在此详细评估了不同维度的稳健性检验策略在当前数据集上的可行性。

## 1. 策略评估与可行性分析

### 1.1 替换核心解释变量法 (实施 ✔️)
*   **方法思路**：在基准回归中，我们将研发投入绝对额取自然对数（`ln_RD`）作为核心解释变量。稳健性检验的一般做法是将其换成“相对比例”指标。利用利润表中的相关字段，我们将原解释变量替换为“**研发投入/营业收入**”。
*   **实施过程**：我们编写了特征补充脚本 `src/extract_revenue.py`，从原始 `利润表.xlsx` 的合并报表中单独剥离出“营业总收入”指标，与面板主表进行关联以构建真实营收为底座的 `RD_Sales_Intensity` (及其一年滞后项)。这一做法剔除了公司不同资产厚度的影响，使得变量直接反映当期营收用来反哺造血科研的比例。

### 1.2 剔除特定样本法与行业固定效应法 (客观受限不予执行 ❌)
*   **实施受阻原因**：我们的宽表数据集（17 家公司的 345 条观测值）虽然包含了详尽的财务指标，但缺乏任何形式的“行业分类代码”（如申万行业分类或证监会2012代码）。
    *   在没有该标签维度支撑的前提下，既无法通过代码自动筛选出异常的特定行业聚类以执行“剔除行业样本”，也因为无标识特征无法在模型层面加入控制行业固定效应因子。受制于此客观条件，本实证不再强行人工分配行业代码执行此类稳健性探讨。

---

## 2. 稳健回归结果：使用研发/营收比 (RD_Sales_Intensity) 执行替换检验

模型重新采用个体固定效应搭配聚类稳健标准误（含季度控制）进行了估计。相对比例指标的代入为本研究贡献了非常具有学术探讨深度的另一视角：

**【当期研发/营收比的影响 (H1-稳健性)】**
*   解释变量变成了 `RD_Sales_Intensity`。
*   系数变为 `-0.2351`。
*   **显著性（P-value）**：$0.9624$ (完全不显著)。
*   **分析**：当剥离掉量纲大小，单纯审视“营业收入中拿多少比例去搞研发”时，原先显著为正的刺激效应不复存在。这揭示了市场对于大规模企业砸绝对额钞票是欢迎的；但对于“赚1块钱花9毛钱搞研发”这种过于激进的“高比例投入”，短期市场秉持观望甚至是警惕态度，因为高研发占比对当期净利润和现金流产生了极具压迫感的透支。

**【滞后一年核心变量：同期研发/营收比的影响 (H2-稳健性)】**
*   解释变量为 `Lag_1yr_RD_Sales_Intensity`。
*   系数由负强力反转飙升至 `+12.151`。
*   **显著性（P-value）**：$0.2616$ (无强统计意义，但呈现绝对正向预期)。
*   **分析**：跨越一年沉淀后，高研发投产占比展现了其“延后资本反哺”能力（从-0.23翻倍扭转至+12.15）。虽然由于样本不足未能通过严格的P值检测，但在方向和量级上完美对应了技术突破与产品变现存在断层期的经济学直觉。即期报表对高盈利敏感（控制变量ROE的系数高达11.8~12.4），而高研发占比要到次年才能部分将其“烧钱劣势”扭转为“壁垒溢价”。

**总体结论**：绝对资金量的投入（基准模型）是推动市值的坚实力量；但在转为考察“下注占比”的相对强度时，效应因风险权重的介入被大幅平折，揭示了估值驱动在总投入绝对值和短期配置相对值之间的割裂现象。模型的个体固定与季度扰动排除均保持极大显著性。
