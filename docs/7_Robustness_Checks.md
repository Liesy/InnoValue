# 稳健性检验 (Robustness Checks)

在得到基准回归支持的结论后，为确保该结果不是由于偶然的参数设定、变量选择或个别异常样本主导的，我们需要进行稳健性检验。

本章围绕更换核心解释变量展开，并在此详细评估了不同维度的稳健性检验策略在当前数据集上的可行性。

## 1. 策略评估与可行性分析

### 1.1 替换核心解释变量法 (实施 ✔️)
*   **方法思路**：在基准回归中，我们将研发投入绝对额取自然对数（`ln_RD`）作为核心解释变量。稳健性检验的一般做法是将其换成“相对比例”指标。利用利润表中的相关字段，我们将原解释变量替换为“**研发投入/营业收入**”。
*   **实施过程**：我们编写了特征补充脚本 `src/extract_revenue.py`，从原始 `利润表.xlsx` 的合并报表中单独剥离出“营业总收入”指标，与面板主表进行关联以构建真实营收为底座的 `RD_Sales_Intensity` (及其一年滞后项)。这一做法剔除了公司不同资产厚度的影响，使得变量直接反映当期营收用来反哺造血科研的比例。

### 1.2 剔除特定样本法与行业固定效应法 (客观受限不予执行 ❌)
*   **实施受阻原因**：我们的宽表数据集（17 家公司的 345 条观测值）虽然包含了详尽的财务指标，但缺乏任何形式的“行业分类代码”（如申万行业分类或证监会2012代码）。
    *   在没有该标签维度支撑的前提下，既无法通过代码自动筛选出异常的特定行业聚类以执行“剔除行业样本”，也因为无标识特征无法在模型层面加入控制行业固定效应因子。受制于此客观条件，本实证不再强行人工分配行业代码执行此类稳健性探讨。

---

## 2. 稳健回归结果：双重核心比例变量替换检验

为了使得稳健性得到充分验证，模型并行采用了两种相对强度指标——“**(研发投入 / 总资产)** (`RD_Intensity`)”与“**(研发投入 / 营业收入)** (`RD_Sales_Intensity`)”来替换原始模型中的绝对金额。

采用个体固定效应搭配聚类稳健标准误（含季度控制）进行估计后，二者给出了非常有趣且高度一致的稳健性反差：

### 2.1 当期强度的影响 (H1-稳健性比较)

*   **模型 A1 (资产维度)**：系数为 `-0.2515`，显著性（P-value） $0.9808$ (不显著)。
*   **模型 B1 (营收维度)**：系数为 `-0.2351`，显著性（P-value） $0.9624$ (不显著)。
*   **综合分析**：不管是相对于家底（总资产）还是流水（总营收），一旦剥离掉绝对金额，单纯审视“把多大比例的钱拿去搞研发”时，短期内对估值 $Q$ 的正向刺激效应均不复存在。这意味着资本市场虽然喜欢“在研发上砸了巨款”的大企业（基准回归），但对当期把过高比例资源用于沉淀科研的行为抱有观望甚至挤压态度，因为此举直接透支了即期利润。

### 2.2 滞后一年同期的影响 (H2-稳健性比较)

*   **模型 A2 (资产维度滞后)**：系数由负反转为 `+8.6901`，显著性（P-value） $0.3063$。
*   **模型 B2 (营收维度滞后)**：系数由负反转飙升至 `+12.151`，显著性（P-value） $0.2616$。
*   **综合分析**：跨越一年沉淀后，高研发投产占比展现了其“延后资本反哺”能力！双维指标同时发生了强烈大逆转（由轻微负面转向巨大的正系数）。虽然由于面板样本时间轴不够长、量级单薄导致未能通过严格的 $P < 0.1$ 检测，但在方向和效应绝对值上完美对应了技术突破起效的延迟性与后续护城河红利。

### 总体结论
无论用资产厚度还是营收水流来框定研发的相对强度，我们都观测到了统一的现象。这证明了我们的结论绝非偶然挑取单一量纲的产物。基准模型中的“研发量”构成当期估值的压舱石；而到了稳健验证的“相对强度”上，则显露出了资本市场对研发“短期风险规避，长期壁垒褒奖”的真实割裂偏好。
