# 变量定义与面板数据汇总 (Variables and Panel Data)

为验证R&D投入对公司估值（Tobin's Q）的影响机制，我们在清理缺失与极端扰动后，计算了一系列经过对数和标准化变形后的实证变量。

## 1. 变量处理清单

*   **被解释变量**
    *   `TobinQ`：作为企业价值评价的直接代理变量，未作变动。
*   **解释变量**
    *   `ln_RD`：企业研发投入的自然对数（$ln(\text{研发投入} + 1)$），用于衡量研发支出的绝对规模增速，加1以避免0对数错误。
    *   `RD_Intensity`：研发投入强度（$\text{研发投入} / \text{总资产}$），用于反映研发在企业资金中占据的重要级或结构配比。
    *   `Lag_1yr_ln_RD` 和 `Lag_1yr_RD_Intensity`：在面板数据组内向下一条时间记录平移一期得到，代表上一期的研发投入努力。
*   **控制变量**
    *   财务质地比率：`ROE` (净资产收益率)、`净利润增长率`、`营业收入增长率`、`资产负债率`。
    *   规模体量控制：`ln_Asset`（$ln(\text{总资产})$），通过自然对数缩小大市值与小微企业的量纲差异，缓解异方差问题。

## 2. 面板组织架构

在特征提取完毕后，数据集被格式化为标准的面板数据：
1.  基于 `Stkcd`（股票代码）标识横截面实体。
2.  基于 `Accper` 解析出来的 `Year`（年份）和 `Quarter`（季度）建立时序维度。
3.  按实体-时间进行了升序排列，并对新数据以 `final_panel_data.csv` 格式封装至 `processed_data`，这是后期用于回归估计的静态宽表明细。

## 💻 附：Python 代码小白通俗解析
这步对应的代码在 `src/02_variable_construction.py` 文件中，它的职责是“打造趁手的工具（变量）”并“给时间打上烙印”。

#### 第一步：数学变形（消除贫富差距）
```python
# numpy (简称 np) 里的 log 也就是自然对数。
# 为什么要用对数？因为有的公司总资产是百亿，有的只有千万。直接放一起比，模型会被大公司带偏。
# 取了对数后，100亿和1000万的差距就被缩小在一个很小的温和范围内了。
df['ln_Asset'] = np.log(df['总资产'].replace(0, np.nan))

# 同理，研发投入也取对数。加 1 是因为高中数学教过：ln(0) 是没有意义会报错的，加个1垫底保平安。
df['ln_RD'] = np.log(df['研发投入'] + 1)
```
**解读**：这就是在用“放大镜”看小蚂蚁，用“望远镜”看大象，把大家的体型都在纸面上拉平到一个可以直接比较的标准。

#### 第二步：找回“去年的记忆” (构造一年滞后项)
我们想知道“去年的研发投入”对“今年的估值”有没有影响，这就需要把每一行数据里，垫上一个名叫 `Lag_1yr_ln_RD` 的新列。
```python
# 先把所有人按公司代码和时间，从小到大排好队
df = df.sort_values(by=['Stkcd', 'Accper'])

# 施展“时间魔法”：把现有的表格复印一份叫做 df_lag
df_lag = df[['Stkcd', 'Accper', 'ln_RD', 'RD_Intensity']].copy()

# 把复印件里所有的时间，硬生生往后推迟整整一年（增加1年）
df_lag['Accper'] = df_lag['Accper'] + pd.DateOffset(years=1)

# 给复印件里的变量改个名，比如原来的“研发投入”改名叫“去年的研发投入(Lag)”
df_lag = df_lag.rename(columns={'ln_RD': 'Lag_1yr_ln_RD'})

# 把原表和复印件，根据【按同一个公司，在同一个时间点】像拼图一样拼起来 (merge)
df = pd.merge(df, df_lag, on=['Stkcd', 'Accper'], how='left')
```
**解读**：打个比方，你想在2023年的日记本旁边，写上2022年你攒了多少钱。电脑怎么操作呢？它是把你2022年的日记本日期强行改成“2023年”，顺便在标题上写个“去年攒的钱”，然后把这页纸贴在你真实的2023年日记旁边。如果去年你没写日记，那这块地方就会留上一块空白（也就是代码里的 `NaN`）。这比机械地往上看一行聪明多了，保证绝不错位！
